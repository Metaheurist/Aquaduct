# `memory_budget`

Logs around **`release_between_stages`** / RAM–VRAM cleanup between pipeline phases (`src/util/memory_budget.py`, callers in `main.py`, workers, render paths).

Enable via **`AQUADUCT_DEBUG=memory_budget`** or **`all`**.
